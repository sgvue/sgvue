# Getting help

- **Questions, bug reports and ideas:** open an issue at
  https://github.com/sgvue/sgvue/issues/new/choose — search the existing issues first.
- Give the SGVue version (Help › About), Windows or macOS and its version, what you did, what
  happened, and the tool that wrote the IFC file (for example Revit 2025, Archicad 28, Tekla).
- **Never attach a confidential model.** Issues are public. If a problem shows only on one of
  your models, describe it, add a screenshot that shows no project information, or make a small
  synthetic IFC file that reproduces it.
- **Security problems** are reported privately: [SECURITY.md](SECURITY.md).
- **Downloads and updates:** https://sgvue.github.io/ and
  https://github.com/sgvue/releases/releases/latest.

SGVue has a single maintainer, so answers are best effort.
